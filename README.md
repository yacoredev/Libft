# Description

Libft is a custom C library that reimplements standard C library functions and provides additional utility functions, including linked list operations.

The goal is to understand C, memory management, pointers, and data structures while building a reusable static library.

# Instructions

Compile the library:

```bash
make
```

This creates `libft.a`.

Available commands:

- `make` or `make all`: Compile the library.
- `make clean`: Remove object files.
- `make fclean`: Remove object files and the library.
- `make re`: Rebuild the library.

To use the library, include `libft.h` and link `libft.a` when compiling your program:

```bash
dst[len_dst]
```
